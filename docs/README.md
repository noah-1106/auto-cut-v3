## 术语表（跨文档统一口径）

| 术语 | 含义 |
|---|---|
| **幕（beat）** | 故事线 `beats[]` 的一格——多轨上的一刀：A 轨主画定时长，B 轨叠加，附字幕/旁白/转场/贴纸/音效/音乐轨 |
| **词轨（words）** | `[{text, start, end}]` 逐词时间戳序列；源素材时间轴，0.1s 量化。下游唯一依赖，换 ASR 供应商零感知 |
| **tier** | 词轨时间戳来源等级：`word`=后端实测（可直用）/ `sent`=句内均分合成 / `vad`=VAD 段插值合成——合成值禁作锚 |
| **dubgate** | 配音门禁 D1-D3：首词对得上 / 末词对得上 / 整体相似≥0.9；不过 exit 1 不渲染 |
| **dubfit** | 配音裁剪闭环：包络定位→掐头掐尾→ASR 回验 |
| **G1 / G2t** | 门禁两域：G1=结构门（渲染前 plan 校验），G2t=词轨时序门（字幕与词轨对齐中位偏移） |
| **R1–R10** | `qc.py` 十条审片规则（结构/时长/音量/冻结帧/字幕同步/响度等），渲后自动跑，blocker 拦交付 |
| **台账（disposition）** | 素材缺陷台账：重说/黑区/音量跳变等四类，只检测+建议窗口，不破坏素材 |
| **包（pack）** | `materials/packs/<pack>/` 仓库级素材包，可被任意项目挂载；挂载=创作决策，走 `/api/pack-mount` |
| **故事线（storyline）** | 同一批素材的一种成片取法；一个项目可含多条（`storylines/<sid>.json`） |
